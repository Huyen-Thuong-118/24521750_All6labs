Lab 1 Sample Plaintext — AES Encryption Demo
=============================================

This file is used as sample input for aestool encrypt/decrypt demos.

The quick brown fox jumps over the lazy dog.
Cryptography is the practice and study of techniques for secure communication.

AES (Advanced Encryption Standard) supports three key sizes:
  - AES-128: 128-bit key (16 bytes)
  - AES-192: 192-bit key (24 bytes)
  - AES-256: 256-bit key (32 bytes)

Modes implemented in this lab:
  ECB, CBC, OFB, CFB, CTR, XTS, CCM (AEAD), GCM (AEAD)

NIST SP 800-38A specifies CBC, CFB, OFB, CTR.
NIST SP 800-38D specifies GCM.
NIST SP 800-38C specifies CCM.
NIST SP 800-38E specifies XTS.
